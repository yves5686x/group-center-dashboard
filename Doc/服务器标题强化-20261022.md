# 前端 1.8.16-rc.7

## 更新内容

- GPU 和硬盘看板共用服务器标题样式：桌面 24px 加粗、手机 22px，增加独立底板和侧边标记，让 2082、2084 等机器名更容易辨认。
- 查看同一台机器下方的显卡、任务或磁盘时，服务器标题保持可见；手机模式下避开顶部导航。
- 机器名称统一显示为 4090A、4090B、4098A、4098B，并同步首页、GPU/硬盘看板、筛选导航、任务查询和统计页面。内部机器 ID、接口参数、保存的筛选标识及分组顺序保持原样。
- 保留 rc.6 的统一红黄绿、深浅主题配色修复、柱状图常显名称及资源缓存策略。

## Docker 镜像

```text
ghcr.io/yves5686x/group-center-dashboard:1.8.16-rc.7
```

本次只更新前端。后端和数据库无需调整。

## 更新现有部署

在当前 Compose 项目中，将 `web` 镜像改为：

```yaml
image: ghcr.io/yves5686x/group-center-dashboard:1.8.16-rc.7
```

在原 Compose 目录中拉取并重建前端：

```bash
docker compose pull web
docker compose up -d --no-deps web
```

使用自定义 Compose 文件名时，为两条命令加上 `-f 实际文件名`。也可以在飞牛 Docker 界面修改当前项目的前端镜像版本并重新部署。更新后刷新浏览器。

保留现有项目名、环境变量、端口、后端和数据卷。附件 `docker-compose.fnos.yml` 为公开示例，已有部署不必覆盖整份配置。

回退时将前端镜像改回 `ghcr.io/yves5686x/group-center-dashboard:1.8.16-rc.6`，再执行相同的拉取和重建命令。
