# GPU 看板与任务查询更新（2026-10-16）

配套版本：前端 `1.8.16-rc.2`、后端 `1.8.10-rc.4`。

## 页面变化

- 看板按 `3090 / 2082`、`2084`、`4090a / 4090b`、`4098a`、`4098b` 分组。桌面端每台机器最多四张 GPU 一行，八卡分两行。窄屏自动减少列数。
- 看板、筛选器、锚点、磁盘看板和任务结果使用相同的简化名称。机器 ID 保持原值，已有选择与 Agent 接口地址继续可用。
- 任务查询移除任务类型。用户名支持下拉完整名单和关键词输入，项目名称支持关键词。
- 原“设备名称”改为“服务器名称”，选择 `4098a`、`4090a` 等标识，按服务器精确筛选。用户和服务器选项合并配置与全部历史任务，不受分页、统计时间段限制。
- 用户统计同时展示常用显卡型号、使用过的显卡型号和常用服务器。常用显卡、服务器和项目按累计运行时长排名，按既有多卡去重规则统计。

## 飞牛测试

更新当前 Compose 的两行镜像，其余参数、数据库地址和数据卷保留：

```yaml
image: ghcr.io/yves5686x/group-center:1.8.10-rc.4
image: ghcr.io/yves5686x/group-center-dashboard:1.8.16-rc.2
```

以上是两个服务各自的 image 行，不能作为完整 Compose 使用。仓库根目录 `docker-compose.fnos.yml` 已更新配套版本；已有私有配置只需改镜像。在原 Compose 项目目录执行：

```bash
docker compose pull backend web
docker compose up -d --no-deps backend web
```

使用其他 Compose 文件名时，给每条命令添加 `-f 实际文件名`。

前端新筛选器依赖后端 `/web/open/gpu-tasks/options`，两端需配套升级。本次无需数据库结构迁移。新的统计缓存键自动重新计算，不需要删数据库或配置卷。

验证看板五组布局；查询时输入部分用户名、部分项目名并选择服务器；检查用户列表包含历史用户，服务器列表包含全部配置与历史服务器；检查用户统计的显卡型号和常用服务器。
