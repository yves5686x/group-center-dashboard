# 前端 1.8.16-rc.6

## 更新内容

- 统一显存、核心、硬盘和系统内存的用量颜色：低于 40% 绿色，40%–79% 黄色，80% 及以上红色。使用一套自然的红黄绿，深浅模式保持相同色值。
- 首页 Ping、Agent 和代理状态统一为在线绿色、离线或检查失败红色，告警黄色；代理成功率、任务状态和硬盘告警使用同一色板。修正 100% 可用率固定显示黄色，兼容数字与百分比字符串。
- 修复多卡 1/2、2/2 标签、用户及项目排名、状态标签、说明文字和图表文字在深浅主题下的对比度。同一多卡任务保留一致分组色。
- “GPU型号在各服务器的任务数对比”每根柱常显服务器名、GPU 型号及任务数，无需悬浮；名称保留完整，较多服务器和手机宽度下可横向滚动。
- 修正 GPU 右键菜单的主题判断，统一筛选按钮及强调文字。
- 延续已有布局、同源实时接口和带内容指纹的资源缓存策略。

## 更新现有部署

在当前 Compose 项目中，仅修改 `web` 镜像：

```yaml
image: ghcr.io/yves5686x/group-center-dashboard:1.8.16-rc.6
```

保持原项目名、后端、环境变量、端口和数据卷，在原 Compose 目录执行：

```bash
docker compose pull web
docker compose up -d --no-deps web
```

如果使用自定义 Compose 文件名，为两条命令加上 `-f 实际文件名`。也可以在飞牛 Docker 界面修改当前项目的前端镜像版本并重新部署。更新后刷新浏览器。

回退时将 `web` 镜像改回 `ghcr.io/yves5686x/group-center-dashboard:1.8.16-rc.5`，再执行同样的拉取和重建命令。

附件 `docker-compose.fnos.yml` 是公开示例。已有部署只需改前端镜像，不必覆盖整份配置；私有数据库和部署配置不会随附件发布。
